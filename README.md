# Realtime Currency Converter

A sleek and modern **currency converter web app** that fetches real-time exchange rates and displays the corresponding country flags. Built with **HTML, CSS, and JavaScript**, it provides an intuitive UI for converting currencies instantly.

## Features

- Convert currencies in real-time using API data.
- Displays country flags for selected currencies.
- Smooth and attractive UI with gradient backgrounds and hover effects.
- Default conversion shows 1 USD → INR on page load.
- Responsive design for mobile and desktop screens.
